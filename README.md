# Esp32-smart-dustbin
ROBO ADI – Smart Dustbin V1.0  An ESP32-based smart dustbin that automatically detects a hand and opens its lid using a servo motor. It features RGB LEDs, an OLED display, a buzzer, and a Wi-Fi dashboard for system updates.  The project includes a custom-designed PCB created using KiCad.
